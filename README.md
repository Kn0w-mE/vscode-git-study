# Time Planner — 使用说明

一个纯前端的时间规划工具。双击 `index.html` 在浏览器中打开即用，无需安装任何软件。

## 快速开始

1. 双击 `index.html` 用浏览器打开
2. 点击左上角标题 `Asuka的Time`，输入你的名字，回车保存
3. 切换到「🧱 方块库」Tab，点击「+ 新建方块」创建任务模板
4. 回到「📅 三日视图」Tab，点击「+ 添加任务」将方块放入时间轴

## 📅 三日视图

这是核心规划页面，显示**昨天 · 今天 · 明天**三列时间轴。

**时间轴**
- 每条竖线 = 15 分钟，每整点标注时间，每 2 小时加粗标线
- 时间范围 6:00 ~ 次日凌晨 2:00，超过 24 点显示为 1:00 / 2:00

**添加任务**
- 点击任意「空闲区域」→ 弹出添加窗口 → 在对应时间点插入任务
- 点击底部「+ 添加任务」→ 选择方块库中的模板或快速新建
- 快速新建的任务会**同步保存到方块库**

**管理任务**
- **点击方块** → 循环切换状态：待执行 → ✅ 完成 → ❌ 破裂
- **拖动方块** → 按住鼠标拖动到目标时间，松手自动吸附 15 分钟格线
- **悬停方块** → 右上角出现红色 ×，点击删除该任务
- **全部完成 / 全部破裂** → 今天卡片底部的批量操作按钮

## 📊 七日概览

显示最近 7 天的汇总视图，4+3 居中排列。

- 每天显示**日期、事件列表（名称+时长）、状态标记**
- 底部进度条：绿色 = 已完成，红色 = 破裂
- 已完成的任务会加删除线

## 📈 数据总结

统计页面，可切换 **今日 / 本周 / 本月**：

- **左侧卡片**：完成数、破裂数、完成率、总时长
- **右侧饼图**：每个已完成任务按**时间占比**分片，同名任务自动合并
- 中心数字 = 已完成总时长

## 🧱 方块库

管理可复用的任务模板：

- **新建方块**：点击「+ 新建方块」，填写名称、时长、分类、优先级、备注
- **编辑方块**：点击方块上的「✏️ 编辑」修改
- **删除方块**：点击「🗑 删除」（已放入时间轴的副本不受影响）

## 🎨 自定义背景

- 点击底部「🖼️ 更换背景」→ 选择本地图片 → 自动压缩保存
- 拖动「透明度」滑块实时调节背景深浅
- 背景图和透明度刷新后自动恢复

## 📁 数据存储

- 所有数据保存在浏览器 `localStorage` 中
- 不同电脑、不同浏览器之间数据完全独立
- **清除浏览器缓存会丢失数据**，建议定期备份

## 📤 分享

将 `index.html` 和 `background.jpg` 放在同一目录下发给对方，浏览器打开即可。

## 🛠 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖
- 无需 Node.js、npm、网络
- 适配 24 寸显示器（1920×1080）
