# Time Planner — 使用说明

一个纯前端的每日时间规划工具，双击 `index.html` 即可使用。

## 快速开始

1. 双击 `index.html` 在浏览器中打开
2. 点击标题 `Asuka的Time` 修改为你的名字
3. 在「方块库」中创建你的任务模板（名称、时长）
4. 回到「三日视图」，点击「+ 添加任务」将方块放入今天的时间轴

## 主要功能

| 视图 | 功能 |
|------|------|
| 📅 三日视图 | 昨天·今天·明天时间轴，15 分钟网格，拖动方块调整时间，点击切换完成/破裂 |
| 📊 七日概览 | 最近 7 天的事件列表和完成率 |
| 📈 数据总结 | 今日/本周/本月统计，按任务时间占比的饼图 |
| 🧱 方块库 | 管理可复用的任务模板 |

## 操作技巧

- **点击方块** — 循环切换状态：待执行 → ✅完成 → ❌破裂
- **拖动方块** — 在时间轴上移动方块，自动吸附 15 分钟格线
- **悬停方块** — 右上角出现 × 按钮可删除
- **点击空闲区域** — 在该时间点添加新任务
- **更换背景** — 底部「🖼️ 更换背景」选择本地图片
- **透明度滑块** — 底部调节背景透明度

## 数据存储

- 所有数据保存在浏览器 `localStorage` 中
- 不同浏览器/电脑之间数据独立，互不影响
- 清除浏览器缓存会丢失数据

## 分享

将 `index.html` 和 `background.jpg` 放在同一目录下，用浏览器打开即可。
